# Fortuna Chung — Opératrice en horlogerie

Luxury-watchmaking inspired resume site, built with Next.js 15 App Router, TypeScript, Tailwind CSS and Framer Motion. Optimized for Vercel.

## Install

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub and import into Vercel — zero configuration.

## Content

Resume data lives per-locale in `lib/data/{fr,en,de,it}.ts` and UI strings in `lib/i18n/dictionary.ts`.
